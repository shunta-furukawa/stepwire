# 記事に踏み順プレイヤーを埋め込む

Step Analyzerで譜面を作り、共有URLを記事本文に次の形式で1行として入れる。

```md
@[step-analyzer](https://step-analyzer-beta.vercel.app/?n=1000010000100001&b=150&f=48L&t=Practice "練習用の踏み順")
```

URLはStep Analyzerのクリップ共有から必要な小節だけ切り出して使える。
`n` / 圧縮された `d`、足指定 `f`、BPM `b`、停止 `s`、難易度 `df`、
変形 `tr`、ハイスピ `hs`、再生速度 `sp`、注目箇所 `hl` とコメント `hc` などはそのまま渡る。
URL中の空白や括弧はURLエンコードし、説明には半角ダブルクォートを含めない。

記事では自動再生せず、再生・速度変更・前後のステップ移動・譜面タップが使える。
編集は「Step Analyzerで開く」から行う。プレイヤーが利用できない場合もこのリンクは表示される。
譜面の配色は元ツールの判読性を維持する。

このブロックはWeb記事専用。動画・読み上げ用テキストには入らない。
動画で必要な説明は通常の本文に書く。動画への譜面アニメーション合成は含まない。

許可する配信元は `lib/content/step-analyzer.ts` に固定している。
ドメイン移行時はこの設定とテストを更新する。任意の外部サイトは埋め込めない。

反映順：Step Analyzerの `/embed` 対応を先に公開し、その後STEPWIRE側を公開する。
既存記事には自動で追加しない。例の譜面は練習用で、実在曲の譜面ではない。
